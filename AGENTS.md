## Как работаем

- Работа по **заходам**: владелец скидывает один промт за раз. Не выходить за рамки захода, не делать фичи будущих заходов, не брать закладки v2/v3 из раздела 12 ТЗ.
- Главное правило: без дедлайнов, думать до кода, проверять себя как тестировщик, после каждого изменения — `pytest`, не угадывать — спрашивать.
- Тексты сообщений (реакции, блокировки, итог темы, привязка) — дословно из ТЗ, не менять.
- Стек: Python 3.12, aiogram 3.30.0, SQLAlchemy 2.0.51 (asyncio), asyncpg, alembic, pydantic-settings, tzdata (обязательно). APScheduler в MVP НЕ подключаем. Запуск: `python -m app.main` из любого каталога.
